   1. 抽樣多個任務（如 T₁、T₃、T₄）

   3. 內迴圈：針對支援集將 θ → θ'_task（任務條件化）

### 為何多任務設定下的 MAML 優於傳統微調
- **任務多樣性驅動元學習。** 模型若能看到多個相關任務，就能學到「少量步驟即有效」的參數初始化。單任務訓練只能對該任務的資料分布做最佳化，無法學出具備快速適應力的初始值。
- **快速適應新關鍵點類型。** 一旦在多個關鍵點類型上 meta-訓練，模型可以在看到少量新任務資料時迅速更新，沿用過去任務所累積的共享表徵。
- **降低災難性遺忘。** 共享的基礎模型同時吸收多種關鍵點的梯度。傳統逐一微調容易覆寫舊知識，而 MAML 透過 meta 更新在多任務間取得平衡。
- **善用 LoRA 容量。** LoRA 低秩適應器成為共享的輕量化參數空間；meta 訓練讓 θ 更容易因應任務的小幅調整，保留 LoRA 微調的低成本優勢。

### 資料集規劃
- **有多個資料集最好。** 針對每種關鍵點類型準備標註樣本，放在同一 loader 內，但務必保留任務 ID，確保支援 / 查詢集能以任務為單位切分。
- **類別有限可用「領域」製造任務。** 若物件類別不多，可依照拍攝環境、光照、布料樣式等建立「偽任務」。只要任務之間存在差異，MAML 就有機會學到快速適應的初始化。
- **注意取樣平衡。** meta-batch 需涵蓋多種任務，否則初始化會偏向樣本最多的類別，削弱多任務帶來的好處。

依此多任務流程，MAML 充當「元優化器」，包在內迴圈的 AdamW 之上，為 LoRA 模型找到更能跨任務快速調整的初始值，給予比傳統單任務微調更佳的泛化與收斂速度。
